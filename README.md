# Blinkit Retail Sales Analytics Dashboard 📊

## Business Problem
Retail businesses need clear insights from sales data to track revenue, product performance, and regional trends for better business decisions.

---

## Project Overview
Built an end-to-end Retail Sales Analytics Dashboard using Excel, SQL, and Power BI to analyze ₹18.62M+ retail sales data.

The project focuses on:
- Revenue & Profit Tracking
- Product Category Performance
- Regional Sales Analysis
- Outlet Performance Monitoring
- KPI-Based Business Reporting

---

## Workflow
- Cleaned raw retail data using Excel
- Performed KPI extraction using SQL queries
- Built interactive dashboard for business reporting
- Generated insights for retail decision-making

---

## Key Features
- Total Revenue Analysis
- Estimated Profit KPIs
- Product-wise Sales Trends
- Regional Sales Insights
- Outlet Performance Analysis

---

## Tools Used
- Excel
- SQL
- Power BI

---

## Business Impact
- Analyzed ₹18.62M+ retail sales data
- Identified high-performing product categories
- Improved visibility into regional sales trends
- Created centralized KPI dashboard for faster reporting

---

## Project Outcome
This project simulates a real-world Retail Business Intelligence workflow where raw sales data is transformed into actionable business insights through data cleaning, SQL analysis, and dashboard visualization.
